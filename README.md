## 📖 Overview

## 🏗️ Architecture & Stack

- Focus on clean code, maintainability, and extensibility.

## 🚀 Quick Start
```bash
git clone https://github.com/santanumajumdar/whisper-voice-notes.git
cd whisper-voice-notes
# Install dependencies
pip install -r requirements.txt # (If Python project)
```
